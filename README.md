# نظام نقاط البيع - POS System

نظام نقاط بيع شامل يدعم إدارة الطاولات وفصل الشيكات ونقل الطلبات.

## الميزات الرئيسية

### 1. إدارة الطاولات
- عرض حالة جميع الطاولات (متاحة/مشغولة)
- إظهار عدد الريسيتات المفتوحة لكل طاولة
- تمييز الطاولات التي تحتوي على أكثر من ريسيت واحد

### 2. نقل الطاولات
- نقل جميع الطلبات من طاولة إلى أخرى
- إمكانية النقل فقط من طاولة مشغولة إلى طاولة متاحة
- تحديث حالة الطاولات تلقائياً بعد النقل

### 3. فصل الشيكات
- تقسيم شيك واحد إلى عدة شيكات منفصلة
- سحب وإفلات الأصناف بين الشيكات
- إنشاء ريسيتات جديدة بمعرفات فريدة
- الاحتفاظ بالأصناف المتبقية في الشيك الأصلي

### 4. اختيار الريسيت
- عند وجود أكثر من ريسيت على طاولة واحدة، يظهر مربع حوار للاختيار
- عرض معلومات كل ريسيت (الرقم، المجموع، عدد الأصناف)
- إمكانية الوصول السريع لأي ريسيت

## كيفية الاستخدام

### تشغيل النظام
1. افتح ملف `newsales.html` في المتصفح
2. ستظهر لك واجهة النظام مع الطاولات المتاحة

### نقل طاولة
1. اضغط على زر "نقل ترابيزة" في الشريط العلوي
2. اختر الطاولة المصدر (التي تحتوي على طلبات)
3. اختر الطاولة الوجهة (المتاحة)
4. اضغط "نقل" لتأكيد العملية

### فصل شيك
1. اختر طاولة تحتوي على طلبات
2. اضغط على زر "فصل ترابيزة"
3. اسحب الأصناف من القائمة الأصلية إلى الريسيتات الجديدة
4. اضغط "إضافة ريسيت جديد" لإنشاء المزيد من الريسيتات
5. اضغط "تأكيد الفصل" لحفظ التغييرات

### عرض الطلبات
- اضغط على أي طاولة لعرض طلباتها
- إذا كانت تحتوي على ريسيت واحد، سيظهر مباشرة
- إذا كانت تحتوي على عدة ريسيتات، ستظهر قائمة للاختيار

## البنية التقنية

### الملفات الرئيسية
- `newsales.html` - الواجهة الرئيسية
- `assets/newsales.css` - ملف التصميم
- `assets/newsales.js` - منطق النظام
- `data/pos-data.json` - بيانات النظام

### التقنيات المستخدمة
- HTML5
- CSS3 مع Flexbox و Grid
- JavaScript الخالص (Vanilla JS)
- تصميم متجاوب
- واجهة باللغة العربية مع دعم RTL

## البيانات

النظام يستخدم بيانات محلية مخزنة في الذاكرة. في التطبيق الحقيقي، يمكن ربط النظام بـ:
- قاعدة بيانات محلية
- API خارجي
- نظام إدارة المطاعم الحالي
